RISC-V Calling Convention
 Six general stages in calling a function [Patterson and Hennessy 2017]
1. Place the arguments where the function can access them
2. Jump to the function
3. Acquire local storage resources the function needs, saving registers as required
4. Perform the desired task of the function
5. Place the function result value where the calling program can access it, restore any registers, 
and release any local storage resources.
6. Since a function can be called from several points in a program, return control to the point of origin.
 Obtain good performance
• Try to keep variables in registers rather than memory
• Avoid going to memory frequently to save and restore these registers.
 RISC-V fortunately has enough registers to offer the best of both worlds
